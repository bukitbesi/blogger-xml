# Security policy

Report suspected vulnerabilities privately to the repository owner. Do not
publish active exploits, verification tokens, cookies, API keys, advertising
credentials or private Blogger exports in an issue.

This repository must not contain:

- Google, Blogger, Cloudflare or GitHub credentials;
- `.env` files;
- private user or subscriber data;
- unpublished content exports;
- generated authentication tokens.

Domain verification strings already present in the public Blogger theme are
treated as public site metadata. Changing them still requires owner approval.
